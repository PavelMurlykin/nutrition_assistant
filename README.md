# Nutrition Assistant

Автономный дневник питания и здоровья для Android 8.0+ на Kotlin и Jetpack Compose. Интерфейс на русском языке. Все данные находятся в Room на устройстве; сервер, учетная запись и интернет не используются. Единственное разрешение итогового приложения — POST_NOTIFICATIONS.

## Возможности

- Дневник по выбранной дате: завтрак, обед, ужин, несколько перекусов, приемы нескольких лекарств, стул, сон, самочувствие и вода.
- Блюда выбираются из редактируемых справочников домашней, ресторанной и магазинной еды. Домашние блюда содержат список ингредиентов.
- Блюда и лекарства ищутся по частичному совпадению во время ввода. Новую запись можно создать из события и сразу выбрать.
- Прием пищи объединяет несколько блюд, в том числе разных типов. Прием лекарств объединяет несколько препаратов с отдельными дозировками.
- Для типов стула 1–2 и 6–7 анализируется предыдущий календарный день: блюда, тип еды, ингредиенты и частота совпадений в истории.
- Четыре независимых ежедневных напоминания с выбором времени и выключателем: завтрак, обед, ужин, туалет.
- Миграция базы 1 → 2 сохраняет старые записи. Изменение справочника не переписывает состав записанных событий.

## Сборка и проверки

Нужны JDK 17 или 21, Android SDK Platform 35, доступный SDK через ANDROID_HOME или local.properties. Gradle Wrapper 8.9 включен в репозиторий. Первая сборка загружает зависимости.

В Android Studio выберите JDK 21 в **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**. Если выбрано `GRADLE_LOCAL_JAVA_HOME`, путь берется из `java.home` в локальном `.gradle/config.properties`. Встроенная в новую Android Studio Java 25 несовместима с Gradle 8.9 и вызывает `Unsupported class file major version 69`. Для сборки из терминала задайте `JAVA_HOME` на JDK 17 или 21. Подробности приведены в руководствах.

```powershell
./gradlew.bat :app:assembleDebug
./gradlew.bat :app:testDebugUnitTest :app:lintDebug
./gradlew.bat :app:connectedDebugAndroidTest
```

Последняя команда требует запущенного Android-эмулятора или подключенного тестового устройства. Debug APK: app/build/outputs/apk/debug/app-debug.apk. На macOS/Linux используйте ./gradlew.

Тесты проверяют аналитику, поиск, составные события, сохранность истории после изменения справочника, миграцию и сценарий создания блюда через интерфейс.

## Ограничения платформы и данных

Напоминания неточные: Android может задерживать их. После перезагрузки или принудительной остановки приложение нужно открыть снова. Автовосстановление при загрузке потребовало бы дополнительного разрешения RECEIVE_BOOT_COMPLETED, которого здесь нет. Синхронизация, облачная резервная копия, импорт и экспорт не реализованы; удаление приложения удаляет локальные данные.

Аналитика показывает наблюдаемые совпадения, а не устанавливает причину заболевания. Пропущенные записи не считаются здоровыми днями. Лекарства сохраняются в дневнике, но их влияние на стул алгоритм не рассчитывает.
