# Прогресс доработки Nutrition Assistant

Обновлено: 18 ноября 2026 года. Основание: [план развития](development-roadmap.ru.md).

## Правила продолжения

- Реализуется один этап за запуск в текущем чате. Незавершённый этап продолжается до начала следующего.
- Готовность определяется результатами и проверками, а не наличием описания в плане.
- После проверок создаётся коммит этапа и выполняется обычный push в `origin/main`. Следующий этап разрешён только после подтверждённой отправки предыдущего.
- Для определения коммита использовать таблицу и историю Git. Если строка указывает «коммит этапа», найти его по номеру и сообщению, затем сравнить с удалённой веткой. Собственный SHA невозможно записать внутри того же коммита.
- Если коммит существует только локально, сначала завершить его отправку. Не выполнять повторную реализацию и не помечать push успешным по локальной записи.

- Добавлена «Выгрузка для анализа» на вкладке «Данные». Выбираются 1–365 календарных дней и разделы, включая исторический состав, полноту и наблюдения аналитики. По умолчанию выбраны 30 дней, комментарии выключены. Сводка показывает формат, период, объём и число записей. Системный выбор файла открывается после «Сохранить файл».
- JSON и Markdown создаются из общей выборки в одной транзакции чтения Room. Сохранены исходные даты, часовые смещения, точность, версии состава, единицы, шкалы и ID событий. Аналитика использует только выбранные данные, указывает исходные события для факторов и выводит явные знаменатели.
- Скрытие заменяет свободные названия и пропускает марки, уточнения, источники и буквальные дозы. Комментарии включаются отдельно и могут содержать личные сведения. Даты и ID сохраняются. Запрос редактируется отдельно. Лимит файла 16 МиБ проверяется во время кодирования.
- Обновлены оба руководства, описание резервных копий и [формат аналитического пакета](analysis-export.ru.md). Проверены относительные ссылки, UTF-8 и git diff --check.
- Сборка assembleDebug, 35 модульных тестов и 96 Android-тестов на Android 17 прошли без ошибок и пропусков. lintDebug — No issues found. Новые проверки охватывают оба формата, вложенный состав, выбранные разделы, скрытие, исходные ID, старые значения и отмену системного выбора с повторной попыткой. Сценарий выбора проверен с тестовым ActivityResultRegistry. Отдельная проверка физических устройств и сторонних поставщиков документов не выполнялась.
