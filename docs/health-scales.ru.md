# Шкалы состояния — версия 1

Реализовано в приложении 0.9.0 (этап 6), Room 7 / JSON 4. Это короткие собственные шкалы последовательной самооценки; клиническая валидность, диагноз и общий индекс здоровья не заявлены. Исходные комментарии не преобразуются автоматически в баллы.

| Показатель | Код и подпись | Период |
| --- | --- | --- |
| Сон, самочувствие | 1 Очень плохое; 2 Плохое; 3 Среднее; 4 Хорошее; 5 Очень хорошее | Сон — завершившаяся ночь; самочувствие — день/момент |
| Стресс | 0 Отсутствовал; 1 Слабый; 2 Умеренный; 3 Сильный; 4 Очень сильный | День/момент |
| Активность | none Не было; light Лёгкая; moderate Умеренная; vigorous Высокая | День/момент |
| Болезнь | none Нет признаков; present Есть признаки; unknown Не знаю | День/момент |
| Влияние болезни | mild Лёгкое; moderate Умеренное; severe Тяжёлое | Необязательно, только при present |
| Категории симптомов | digestive Пищеварительные; respiratory Респираторные; fever Повышение температуры; other Другие | Необязательно, несколько при present |
| Вид активности | walking Ходьба; running Бег; cycling Велосипед; strength Силовая нагрузка; housework Домашние дела; other Другая | Необязательно, только при нагрузке |
| Срочность позыва | 0 Нет; 1 Умеренная; 2 Сильная | Необязательно, событие стула |
| Боль | 0 Нет; 1 Слабая; 2 Умеренная; 3 Сильная | Необязательно, событие стула |
| Стул | Прежний Bristol 1–7, подписи без изменения | Событие; старый 0 — не оценено |

«Не заполнено» — null/отсутствие записи, а не норма. Болезнь unknown — осознанный ответ, отличный от пропуска. Диагноз не требуется; пользователь может добавить его в комментарий. Коды главных шкал хранятся строками, sleep/stool — целыми; у оценок сохраняются подпись и версия. [Синтетический JSON 4](examples/nutrition-backup-v4.json) содержит полный машинный словарь.

## Периоды и сводки

Одна оценка за день на показатель хранится отдельно от моментов; моменты могут повторяться, без точного времени либо с явно заданными часами/UTC-смещением/поясом. Создание записи не задаёт время события. Среднее моментов не подменяет дневной ответ. Сводка активности: максимум отмеченной интенсивности, сумма известных минут, число нагрузок без длительности; пропущенная длительность не считается нулём. Разные показатели не суммируются.

Сон можно оценить без часов. Пробуждения необязательны, 0 — известное отсутствие. Интервал в постели требует обеих границ; даты сна могут оставаться неизвестными у прежних записей. Длительность по местным часам не доказывает, сколько человек спал, и не корректируется на перевод часов.

Питание/симптомы подтверждаются отдельно с явным итогом стула. Изменения еды снимают подтверждение питания; здоровья, стула, сна или лекарств — симптомов. Пустой день не подтверждается автоматически. Текущая аналитика пока не использует новые шкалы и подтверждения (этап 8).

## Проверка готовых инструментов

Проверено 17 ноября 2026 года. [WHO-5](https://www.who.int/publications/m/item/who-ucn-msd-mhe-2024.01) оценивает психическое благополучие за две недели, состоит из пяти утверждений с шестью вариантами. Поэтому он не выбран для одного ежедневного физического самочувствия. Страница публикации указывает CC-BY-NC-SA 3.0.

[University of Pittsburgh](https://www.sleep.pitt.edu/research/measures-and-study-instruments) требует запрос разрешения на инструменты сна и отдельно описывает условия исследовательского/образовательного и коммерческого использования PSQI. Его текст и подсчёт не встроены. Решение этого этапа — собственная ежедневная самооценка сна без имени и результатов PSQI.

Подсказка интенсивности пересказывает [CDC, Talk Test](https://www.cdc.gov/physical-activity-basics/measuring/index.html): умеренная нагрузка обычно позволяет разговаривать, но затрудняет пение; высокая ограничивает речь короткими фразами между вдохами. Это ориентир интенсивности, а не валидированная шкала всего дня. Внешняя ссылка открывается браузером только по нажатию; новое интернет-разрешение приложению не добавлено.

## Проверки и ограничения

Проверки охватывают границы, пропуски/ноль, зависимые поля, день/момент, редактирование и UUID, старые тексты, миграции, время с переводом часов, JSON и откат, форму без текста, сохранение черновика и крупный шрифт. Объём и итоги итогового прогона фиксируются в [журнале](development-progress.ru.md). Цель заполнения обычного дня примерно за минуту на реальном пользователе пока не измерена; автоматический тест подтверждает возможность выбрать пять ответов без набора текста.
