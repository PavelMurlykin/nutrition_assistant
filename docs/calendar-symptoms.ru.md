# Календарь симптомов и хронология — этап 7

Реализовано в версии 0.10.0 (code 11). Схема Room 7, JSON 4 без новых полей. Эти представления вычисляются из событий и подтверждений; готовность проверяется по [журналу](development-progress.ru.md).

| Данные дня | Отметка | Значение |
| --- | --- | --- |
| Хотя бы один Bristol 6/7, включая смешанный день | Красный ! | Записан жидкий стул; число эпизодов отдельно |
| Только тип 5 без подтверждения | ? | Мягкий стул; итог симптомов не подтверждён |
| Итог no_diarrhea и symptoms_complete | ✓ | Пользователь подтвердил отсутствие жидкого стула |
| Итог no_stool и symptoms_complete | ✓ | Пользователь подтвердил отсутствие стула; отдельная подпись |
| Нет записей или подтверждения | ? | Неизвестный итог, включая будущие даты |

Подтверждение питания независимо. Цвет дополнен символом и описанием для озвучивания; ячейка сообщает счётчики и оба подтверждения. Более толстая рамка обозначает сегодня, фон — выбранный день. Они сохраняются при наличии !. Удаление последнего 6/7 снимает ! и сохраняет неизвестность до нового явного подтверждения. Импорт обновляет календарь через те же наблюдаемые таблицы.

Это продуктовое правило для поиска записей, без постановки диагноза. Клиническое описание учитывает частоту и отличие от обычного состояния, а не один номер Bristol: [NIDDK, симптомы диареи](https://www.niddk.nih.gov/health-information/digestive-diseases/diarrhea/symptoms-causes), проверено 17 ноября 2026 года. Само правило подсветки задано планом приложения.

Сводка — за весь видимый месяц, включая будущие неподтверждённые даты. Соседние месяцы сетки не входят. Показаны число дней и эпизодов 6/7 отдельно, эпизоды типа 5, подтверждённые дни без жидкого стула и количества подтверждений питания/симптомов. Загрузка имеет собственную подпись. Список дат фильтруется по 6/7; сетка сохраняет контекст. Нет результатов означает отсутствие записанного эпизода, не норму. Выбор строки открывает дневник/хронологию этой даты; фильтр сохраняется при пересоздании.

Хронология показывает еду, лекарства, стул, здоровье и сон, исторические сведения и комментарии. Точные события сортируются по фактическому Instant с учётом исходного UTC-смещения; исходная локальная дата календаря не меняется. Равные времена не устанавливают взаимный порядок. Записи только с датой находятся отдельно с подписью неизвестного порядка. Дневные оценки и сон также отделены; время создания и время подъёма не придумывают момент дневного воздействия. Вода остаётся в собственной карточке. По шесть записей каждой группы показаны сразу, остальные доступны в полном просмотре; редактирование — в карточках ниже.

Проверяются смешанный день, несколько эпизодов, 5 и legacy 0, отсутствие данных, оба вида явного отрицательного итога, независимая полнота, редактирование и удаление последнего 6/7, границы месяцев/високосный год, перенос JSON и обновление Room Flow. UI-проверки охватывают фильтр, восстановление, переход между месяцами, доступные подписи, хронологию и крупный шрифт. Точные итоги и ограничения устройства фиксируются в журнале; вычисления новой аналитики относятся к этапу 8.
